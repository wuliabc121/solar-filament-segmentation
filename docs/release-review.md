# 发布校验

发布内容为团队整合项目的源码、运行入口、依赖配置、实验划分及聚合指标。`docs/random20_metrics.json` 记录固定随机验证结果及对应的实验编号。训练暴露差异和 M4 验证范围见 `README.md` 与 `docs/methods.md`。

源码副本运行 121 项测试并全部通过。官方参考实现和历史运行目录相关的检查需还原对应文件。本机加载原有权重通过 M1/M2/M3 哈希检查，并通过 M3 默认入口完成一张原图的 CPU 推理，输出 6 个实例。该单图检查用于验证发布副本的运行入口。模型权重和图像由使用者按说明放置。

`release_manifest.sha256` 记录发布文件内容的 SHA256。官方数据、预测文件、权重、演示稿、依赖环境及本机日志均独立于源码分发。
